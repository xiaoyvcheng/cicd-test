## 4. SSH 部署密钥

| 项 | 值 |
|----|-----|
| 本机私钥路径 | `.secrets/cicd-deploy`（已在 `.gitignore`，**勿提交**） |
| 公钥路径 | `.secrets/cicd-deploy.pub` |
| 远端用户 | `deploy` |
| 已授权主机 | `deploy@10.0.0.12`（app-dev）、`deploy@10.0.0.11`（app-prod） |
| 连通测试 | `ssh -i .secrets/cicd-deploy deploy@10.0.0.12 hostname` |

`deploy` 对 `cicd-demo` 的 systemctl 有部分 NOPASSWD（见阶段0 sudoers）；`stop`/`disable` 若无权限需用有 sudo 的账号。

| 角色 | IP | 常用 SSH 用户 | 应用账号 | 说明 |
|------|-----|---------------|----------|------|
| platform | 10.0.0.13 | 各机自管 OS 口令 | — | GitLab + Jenkins + Registry `:5050` |

| app-prod | 10.0.0.11 | `deploy`（密钥） | Compose：`deploy` | 8092 |

> OS 登录口令（如 `ubuntu`/`platform` 的 sudo 密码）未统一入库；以各机创建时为准。日常部署用 **`deploy` + 密钥** 即可。

## 6. 易混概念（别用错）

| 东西 | 是什么 | 不是什么 |
|------|--------|----------|
| Jenkins `initialAdminPassword` | 首次解锁用 | 日常 `root` 登录密码 |
| GitLab `initial_root_password` | 安装后 24h 内初始 root | 改密后的日常密码（本环境已改为上表） |
| GitLab PAT | API / Jenkins 凭据 / `docker login` | GitLab 网页登录密码 |
| `deploy` SSH 密钥 | 部署用 | GitLab/Jenkins 网页登录 |
